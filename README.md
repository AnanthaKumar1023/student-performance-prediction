# Student Performance Prediction System

## Project Overview

This project uses Machine Learning to predict student performance based on academic and personal factors.

## Features Used

- Study Hours
- Attendance
- Assignments Completed
- Sleep Hours
- Previous Score

## Machine Learning Algorithms

### 1. Linear Regression
Used to predict student marks.

### 2. Logistic Regression
Used to classify students as Pass or Fail.

## Dataset

The dataset contains 32 student records.

## Model Results

- MAE: 1.05
- MSE: 1.34
- RMSE: 1.16
- R² Score: 1.0
- Pass/Fail Accuracy: 100% on the current test split
